# Schedules for this agent

Copy an instruction into a scheduled task. **Run it once by hand first.**

## Daily brief — weekdays 08:00
```
Build today's morning brief using the morning-brief skill.
Save it to briefs/ and show it to me.
Do not reply to, archive, accept or decline anything.
Replace progress.md with today's state and tomorrow's follow-ups.
```

## End-of-week sweep — Friday 16:00
```
Read this week's files in briefs/. List anything flagged as
time-sensitive that still looks unresolved. Keep it under 8 lines.
Add any still-open items to the "Next step" in progress.md
(replace the file, don't append).
```

## Week ahead — Sunday 19:00
```
Look at my calendar for next week. Tell me: the busiest day,
any clashes, any meeting I'll need to prepare for, and my longest
free block. Under 8 lines. Don't change anything in my calendar.
```
