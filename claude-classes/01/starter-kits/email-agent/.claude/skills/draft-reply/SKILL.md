# Drafting a reply

1. Read the whole thread, not just the last message.
2. Match the tone rules in memory.md.
3. Keep it shorter than the message you're replying to, unless a longer
   answer is genuinely needed.
4. If you'd need a fact you don't have (a date, a price, a decision),
   write `[CHECK: …]` in the draft instead of guessing.
5. Save it as a **draft** in Gmail. Never send.
